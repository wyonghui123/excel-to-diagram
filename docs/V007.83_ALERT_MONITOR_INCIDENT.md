## 2. 修复指南 (2 选 1)

### 方案 A: 手动跑 PowerShell (管理员) — 1 分钟

**步骤 1**: 右键开始菜单 → "Windows PowerShell (管理员)" 或 "终端 (管理员)"

**步骤 2**: 粘贴以下命令 (整个块):

```powershell
# Stop old task
schtasks /End /TN "\yonaa_alert_monitor"

# Delete old task
schtasks /Delete /TN "\yonaa_alert_monitor" /F

# Read XML, fix path, save
$oldPath = "D:\filework\release-prep-worktree"
$newPath = "D:\filework\worktrees\release-prep"
$xmlPath = "$newPath\tools\yonaa_alert_monitor.xml"
$tempXml = "$newPath\tools\yonaa_alert_monitor_fixed.xml"
$bytes = [System.IO.File]::ReadAllBytes($xmlPath)
$enc = [System.Text.Encoding]::Unicode
$xmlContent = $enc.GetString($bytes).Replace($oldPath, $newPath)
$enc.GetBytes($xmlContent) | Out-File $tempXml

# Create new task
schtasks /Create /TN "\yonaa_alert_monitor" /XML $tempXml /F

# Verify
schtasks /Query /TN "\yonaa_alert_monitor" /V /FO LIST | Select-String "要运行的任务|起始于|状态"

# Cleanup
Remove-Item $tempXml -Force
```

**步骤 3**: 等 5 分钟, 验证下次运行成功:
```powershell
schtasks /Query /TN "\yonaa_alert_monitor" /V /FO LIST | Select-String "上次|结果"
```

期望: `上次结果: 0` 或 `0x0` (成功), 路径是 `D:\filework\worktrees\release-prep\tools\`
