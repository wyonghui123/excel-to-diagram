#### **上传文件（4 种方式，推荐方式 1）**


**方式 2: 用 finalshell 内置的文件浏览器（左侧）**

**方式 3: 用 rz 命令（如果上面都不行）**

```
⚠️ 注意：这种上传是 ASCII 模式，可能会损坏 .sh 文件！
       仅适合上传 .zip / .tar.gz 二进制文件
```

**方式 4: 通过 sftp 命令（最通用）**
```
在 FinalShell 终端输入：
```

```bash

echo "[2] deploy-full:" && ls -la /tmp/deploy-full-v20260630_001.sh && \

```

**预期看到** 5 行（每个文件），同时会出现 md5sum 的 hash。

> **MD5 对比**（确认 zip 没上传坏）：
> 在你本地 Windows 机器上跑：
> ```powershell
> cd D:\filework\excel-to-diagram
> Get-FileHash deploy-v20260630_001.zip -Algorithm MD5
> ```
> 把本地的 hash 和远程的 hash 比一下，**必须完全一致**。
> 如果不一致 → 上传中断 → 重新上传

## ❓ 常见上传问题

### Q1：拖拽到 MobaXterm 后没反应
**A**: 
- 检查 MobaXterm 版本 → MobaXterm 17+ 才支持拖拽
- 老版本请用上传按钮（左侧 SFTP 浏览器右键 → Upload）
- 或者用 `sftp` 命令

### Q2：上传后文件大小不一致
**A**: 中断了，重新上传。MobaXterm 偶尔会在大文件传输时掉线。

### Q3：上传到 /tmp/ 后，deploy 脚本找不到文件
**A**: 99% 是上传到了 `/tmp` 而不是 `/tmp/`。检查路径。脚本默认找 `/tmp/deploy-v...zip`。

### Q4：上传后右键 show in folder 显示 0 字节
**A**: 立刻删除，重新上传。这个问题一般是网络中断。

### Q5：我无法拖拽（MobaXterm 设置问题）
**A**: 
- MobaXterm → Settings → SSH → 勾选 "Display graphical SFTP browser"
- 重启 MobaXterm
- 或在终端里用 `sftp` 命令替代（看上面方式 4）
