## 5. 给未来 AI Agent (包括我自己下次 session) 的 4 条铁律

### 5.1 身份铁律 — 5 步身份检查 SOP

```bash
# 每次 session 开始必跑
echo "1. USER:" && git -C <cwd> config --get user.name && git -C <cwd> config --get user.email
echo "2. WORKTREE:" && basename $(pwd)
echo "3. BRANCH:" && git -C <cwd> branch --show-current
echo "4. HEAD AUTHOR:" && git -C <cwd> log -1 --pretty=format:"%an <%ae>"
echo "5. DIRTY:" && git -C <cwd> status --porcelain | wc -l
```

**5 步能告诉你 100% 你是谁, 你在哪, 你做了什么**.

### 5.2 归属铁律 — dirty 几乎都是你自己

| worktree 状态 | dirty 来源 |
|---|---|
| **HEAD 是你的** + worktree 你在用 | **dirty = 你的 work-in-progress, 必须 commit** |
| HEAD 是别人 + 你在用 | dirty 可能混 (前 session 残留), 小心处理 |
| HEAD 是你 + dirty 巨大 (1000+) | 之前 session 没 commit, 巨大累积 |

**默认假设: dirty 是你的**. **不要轻易"不动它们"**.

### 5.3 不要推测 — 看 config

| 错的 | 对的 |
|---|---|
| "用 git shortlog 看哪个 author commit 多" | "用 git config 看自己" |
| "我工作流是 dev agent, 不会做 PM 部署" | "看 worktree 是不是 release-prep" |
| "V047 是主力, V008 是 V047 做的" | "V047 在别处, release-prep 是我" |
