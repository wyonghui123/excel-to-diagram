### 2.3 完整 Rules 文档（[/ide/rules](https://docs.trae.cn/ide/rules)）

#### 2.3.1 4 种生效方式

| 方式 | alwaysApply | 其他字段 | 描述 |
|------|------------|---------|------|
| **始终生效** | true | 无 | 所有对话都生效 |

#### 2.3.2 3 层嵌套结构（已确认 v5.4 错误）

v5.4 误判："仅支持 2 层嵌套"
**v5.5 真相**：**最多支持 3 层嵌套**

```
.trae/rules/
├── global-rules.md
├── module-a/                       # 第 1 层
│   ├── rules-a.md
│   ├── submodule-a1/               # 第 2 层
│   │   └── rules-a1.md
│   └── submodule-a2/
│       └── submodule-a2-b1/        # 第 3 层（最深可识别）
│           └── rules-a2-b1.md
└── module-b/
    └── rules-b.md
```

#### 2.3.3 子目录规则

`.trae/rules/` 任何子目录下都可独立配置规则，仅在 AI 读取该子目录文件时生效：

```
my-project/
├── .trae/rules/global-style.md
├── frontend-module/
│   ├── AGENTS.md
│   └── .trae/rules/react-best-practices.md  # 仅 frontend-module 生效
└── backend-module/
    └── .trae/rules/api-design.md             # 仅 backend-module 生效
```
