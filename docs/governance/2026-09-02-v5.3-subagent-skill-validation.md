## 三、测试发现 6 个问题

### 🔴 P1-1: e2e-testing Skill 重名冲突

**位置**: `excel-to-diagram/.trae/skills/e2e-testing/SKILL.md`

**问题**: 新建文件与已有 SK-003 `e2e-testing`（commit `7e3c2a4`，2026-06-13）完全重名

```bash
$ grep "^name:" .trae/skills/*/SKILL.md | grep e2e
.trae/skills/e2e-testing/SKILL.md:name: e2e-testing   # 新建（粗）
.trae/skills/e2e-testing/SKILL.md:name: e2e-testing   # SK-003 已有（权威）
```

**风险**:
- Trae IDE 加载时随机选一个，导致用户调用行为不一致
- 注册表（INDEX.md）只有 SK-003，新建文件无注册

**修复**: 删除新建 `e2e-testing/SKILL.md`，保留 SK-003 权威版本

### 🔴 P1-2: 新建 Skill frontmatter 缺必需字段

**位置**: `database-snapshot/SKILL.md`、`git-workflow/SKILL.md`、`frontend-debugging/SKILL.md`

**问题**: 缺 `_TEMPLATE/SKILL.md` 要求的 5 个必填字段

```yaml
# 修复前（仅 2 个字段）
---
name: database-snapshot
description: ...
---

# 修复后（7 个字段，符合模板 v1.0）
---
name: database-snapshot
description: ...
version: "0.1.0"
triggers: ["备份数据库", ...]
inputs: ["tools/db_fingerprint.py", ...]
outputs: ["snapshots/*.db"]
tools: ["filesystem", "bash", "sqlite"]
author: "AI"
last_updated: "2026-09-02"
---
```

**风险**: Trae IDE 可能无法识别 Skill（缺 version/author/triggers 会导致加载异常）

**修复**: 补全 5 个必填字段

## 六、关键决策

1. **description + triggers 分层**: description 简短概括（便于 embedding），triggers 详列触发短语（便于 grep/match）
2. **template 强制合规**: 遵循 `_TEMPLATE/SKILL.md` 的 7 字段 frontmatter 规范，避免 IDE 加载异常
3. **同名 Skill 冲突策略**: 与已有 Skill 重复时，删除新建文件而非覆盖权威版本
4. **disallowedTools 边界**: 只读型 Subagent（reviewer/auditor）声明，写入型（test-writer）不声明
