## 一、实施清单

### 1.1 ✅ .agents/skills/ 镜像（31 个 junction）

**实施方法**：
- 使用 Windows Directory Junction（无需管理员权限）
- 镜像 `.trae/skills/` 31 个 Skill 到 `.agents/skills/`
- 跳过 `_TEMPLATE` 和 `_ROUTER`（内部模板）
- 重命名时 `.trae/skills/` 优先于 `.agents/skills/`

**命令（已执行）**：
```powershell
$src = 'd:\filework\excel-to-diagram\.trae\skills'
$dst = 'd:\filework\excel-to-diagram\.agents\skills'
Get-ChildItem -Path $src -Directory | ForEach-Object {
    if ($_.Name -notin @('_TEMPLATE', '_ROUTER')) {
        $link = Join-Path $dst $_.Name
        $target = Join-Path $src $_.Name
        New-Item -ItemType Junction -Path $link -Target $target
    }
}
```
