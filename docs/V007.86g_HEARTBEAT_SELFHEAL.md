## 5. V007.86g 关键设计

### 5.1 心跳设计

**alert_monitor_v0760.py [HEARTBEAT-V00786F]**:
- 每次跑写一行
- 包含 check_id (时间戳) + ok/total 统计
- check_alert_monitor_health.py 找这行, 验证监控在跑

**5 项检查**:
1. log 存在 + 大小合理 (200B - 10MB)
2. log 最新 10 min 有新行
3. [HEARTBEAT-V00786F] 标记最新 10 min
4. log 无异常模式 (Traceback / ERROR / FATAL)
5. state.last_heartbeat_ts 最新 15 min

### 5.2 自愈设计

**auto_heal_scheduler.py 自愈策略**:
- 1 小时最多自愈 6 次 (防无限循环)
- 10 分钟冷却 (防抖动)
- 连续 3 次失败 -> 启动 daemon 备份
- 飞书告警 (V007.63 飞书心跳机制复用)

**为什么用 schtasks /Run 而不是 schtasks /Create**:
- /Run 强制跑一次现有任务 (不破坏配置)
- /Create 会重新创建任务 (可能跟现有冲突)
- /Run 保留任务历史 (last run time / result)

### 5.3 generate_scheduled_task_xml.py 升级

**V007.86d** (5 days ago):
- 1 个模式: .bat wrapper
- --script = .bat 路径

**V007.86g** (现在):
- 2 个模式: .bat wrapper (V007.86d) + pythonw + script (V007.86e)
- --python + --script-args = pythonw mode
- 不传 --python = .bat mode (兼容 V007.86d)
