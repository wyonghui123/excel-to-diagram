## 6. 永久修复 (用户操作)

**需要管理员权限**. 1 分钟修复指南 (V007.83 报告 方案 A 的 2.0 版):

```powershell
# 1. 打开管理员 PowerShell
#    右键开始菜单 -> Windows PowerShell (管理员) 或 终端 (管理员)

# 2. 粘贴以下命令
$newPath = "D:\filework\worktrees\release-prep"
$xmlPath = "$newPath\tools\yonaa_alert_monitor.xml"
$tempXml = "$newPath\tools\_yonaa_alert_monitor_v0760.xml"

# 3. 读 XML + 改路径 + 保存 (UTF-16 LE, no CRLF)
$bytes = [System.IO.File]::ReadAllBytes($xmlPath)
$xmlText = [System.Text.Encoding]::Unicode.GetString($bytes) -replace 'D:\\filework\\release-prep-worktree', 'D:\filework\worktrees\release-prep'
# 注意: 不能用 Out-File (它加 CRLF 破坏 UTF-16)
$fixedBytes = [System.Text.Encoding]::Unicode.GetBytes($xmlText)
[System.IO.File]::WriteAllBytes($tempXml, $fixedBytes)

# 4. Create task
schtasks /Create /TN "\yonaa_alert_monitor" /XML $tempXml /F

# 5. Verify
schtasks /Query /TN "\yonaa_alert_monitor" /V /FO LIST | Select-String "要运行的任务|状态"

# 6. Cleanup
Remove-Item $tempXml -Force
```

- 5 分钟后 `上次结果: 0` 或 `0x0`
