### V007.50 P0 修复

**StepScopeSummary.vue 加 watch**:

```js
const RELATIONSHIP_WARN_THRESHOLD = 100
let _lastWarnedStep1Key = null

function warnTooManyRelationshipsStep1(count, chartType) {
  if (chartType !== 'businessObject') return
  const isAbove = count > RELATIONSHIP_WARN_THRESHOLD
  const wasAbove = _lastWarnedStep1Key !== null
  if (wasAbove && isAbove) return  // 已在 above, 不重复
  if (!isAbove) {
    if (wasAbove) _lastWarnedStep1Key = null  // 重置
    return
  }
  _lastWarnedStep1Key = `above:${count}`
  ElNotification({
    title: '业务对象图关系数量过多',
    message: `当前关系数量 ${count} 条, 超过推荐阈值 ${RELATIONSHIP_WARN_THRESHOLD} 条, 可能影响图表加载和渲染性能。建议缩小对象和关系范围, 或采用服务模块图查看整体结构。`,
    type: 'warning',
    duration: 8000,
    position: 'bottom-right',
    showClose: true,
  })
}

watch: {
  'total.objectRelations': {
    handler(newCount) {
      if (typeof newCount !== 'number') return
      warnTooManyRelationshipsStep1(newCount, this.chartType)
    },
    immediate: true
  }
}
```

**StepChartType.vue 传 chartType prop**:
```vue
<StepScopeSummary
  :center="center"
  :incremental="incremental"
  :total="total"
  :chart-type="chartType"
/>
```

**关键**:
- `total.objectRelations` 来自 `displayStats.total.objectRelations` = 中心internal + cross-boundary 关系
- **用户在 step 0 调整范围时立即弹** (watch immediate)
- 防重复: wasAbove/isAbove 状态机
- 不影响 V007.49 (BO 图渲染时仍弹)
