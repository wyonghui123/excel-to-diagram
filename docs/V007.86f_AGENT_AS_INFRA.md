## 2. V007.86 治理的 4 个盲点

### 2.1 盲点 1: Dev Agent 自己的可靠性没被监控

- 失忆了我自己可能不知道 (V007.76 就是)

### 2.2 盲点 2: alert_monitor_v0760.py 自身不监控自己

**当前**:
- 监控 7 个远程服务 (172.20.59.7)
- 5 分钟跑一次
- log 写成功 = "全部 OK"

**问题**:
- log 写成功 ≠ 监控在工作
- 如果 alert_monitor_v0760.py 自身逻辑错 (e.g. 永远返回 OK), log 写成功, 但**实际什么都没监控**
- 这是 **silent failure** (静默失败)

### 2.3 盲点 3: 计划任务失败但没告警

**V007.83 教训**:
- 13.5 小时 162 次全失败
- 飞书**没收到**任何告警 (exit code != 0 不触发)

**问题**:
- 飞书告警是"出问题时告警"
- 飞书**不**告警"监控自身挂了"
- 飞书**不**告警"任务 162 次失败"

### 2.4 盲点 4: 任务系统的自愈 (self-healing) 能力

**当前**:

- V007.86 daemon 临时方案 (V007.86 启动, 10:11 停)

- **真正的 SRE** = 让系统自己诊断 + 恢复

## 3. V007.86f 治理方案 (4 层)

### 3.1 Layer 1: 心跳 (Heartbeat) — 监控监控

**问题**: 怎么知道"监控在工作"?

**方案**: 加 `check_alert_monitor_health.py`:
- 5 分钟跑一次 (跟 alert_monitor 同步)
- 检查:
  - alert_monitor_v0760.py log 最近 5 分钟有新条目
  - log 最新一行有 `[OK] 全部健康` 或 `[FAIL]`
  - log 长度异常 (太长 = 重复, 太短 = 跳步)
  - alert_monitor_v0760.py 进程在跑 (可选)
- 异常 → 飞书告警 "监控自身异常"

**额外**: alert_monitor_v0760.py 内部加"自检心跳":
- 跑完一次, 在 log 写一行 `[HEARTBEAT] v00786f`
- 外部脚本检查这行是否存在

### 3.2 Layer 2: 任务自愈 (Self-healing) — 失败自动恢复

**问题**: 任务挂了, 没人重启

**方案**: 加 `auto_heal_scheduler.py`:
- 5 分钟跑一次
- 检查计划任务 `\yonaa_alert_monitor` 的 "上次结果"
- 如果 != 0:
  - 自动 `schtasks /Run /TN ...` 强制跑一次
  - 飞书告警 "任务自动重启"
  - 写 log `[HEAL] 任务重启 from failure X to ...`
- 如果 3 次都失败:
  - 飞书告警 "任务无法自愈, 需人工介入"
  - 自动启动 daemon 备份方案 (V007.86 临时方案自动化)

### 3.3 Layer 3: Agent 自身健康 (Agent Self-health)

**问题**: Dev Agent 自己挂掉 / 失忆, 没人知道

**方案**: 加 `check_agent_health.py`:
- 5 分钟跑一次
- 检查:
  - git status 干净 (没有未提交改动 ≥ 30 min)
  - git HEAD 跟 origin 同步 (1+ commit ahead 超过 24h)
  - alert_monitor_config_state.json 最近 10 min 写过
  - 计划任务上次结果 = 0
- 异常 → 飞书告警 "Agent 健康异常: ..."

**额外**: Agent 启动时**强制跑** §0.6 身份检查 SOP (V007.80):
- 知道自己在哪个 worktree
- 知道 HEAD SHA
- 知道最近 3 个 commit
- 不知道 → 自动停下来, 不操作

### 3.4 Layer 4: 任务基础设施清单 (Infrastructure Manifest)

**问题**: 我不知道"基础设施的所有组件"是什么

**方案**: 写 `infra_manifest.json`:
```json
{
  "v007.86f": {
    "components": {
      "alert_monitor": {
        "script": "tools/alert_monitor_v0760.py",
        "task_name": "\\yonaa_alert_monitor",
        "interval_sec": 300,
        "expected_log_size_min": 100,
        "last_known_good": "532cccb"
      },
      "agent_self_health": {
        "script": "tools/check_agent_health.py",
        "task_name": "\\yonaa_agent_health_monitor",
        "interval_sec": 300,
        "expected_log_size_min": 50
      },
      "auto_heal": {
        "script": "tools/auto_heal_scheduler.py",
        "task_name": "\\yonaa_auto_heal",
        "interval_sec": 300
      }
    },
    "alerts": {
      "im": "lark_app",
      "chat_id": "<from env>"
    }
  }
}
```

**用途**:
- Agent 启动时**必读**这个 manifest
- 知道"基础设施 = 3 个组件"
- 任何组件异常, Agent 都能识别
